# Healthy Me Beta v0.2

This release replaces the v0.1 developer scaffold with the first product-shaped build.

Highlights:
- Three-step onboarding
- Persistent profile and app data
- Today dashboard
- Progress page with weight trend and body measurements
- Provider-aware connections
- Editable bloodwork with CSV/XLSX import
- Sex-aware hormone marker list
- Evidence-aligned sleep target logic
- Wellness plan generated from available user inputs
