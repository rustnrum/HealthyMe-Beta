# Healthy Me v0.3.2

- Connected Sources is now detection-driven instead of a static vendor catalog.
- Activity exposes the selected step provider and freshness timestamp.
- Distance records are normalized to miles from their actual Health Connect unit and tied to one motion provider to avoid multi-provider double counting.
- Sleep Plan adds a draggable circular bedtime/wake-time planner with saved schedule and planned duration.
- Primary app bar adds a Healthy Me sections launcher. Fitness is active; Diet is reserved for a future module with Diet / Menu / Planning / Grocery List bottom navigation.
